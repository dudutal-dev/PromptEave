# שביל ישראל – מתכנן ומלווה המסע 🥾

אפליקציית ווב (PWA) בעברית לתכנון וביצוע מסע בשביל ישראל: מקטעים, לינה, מים, עונות, מפה, מצפן, GPS, יומן מסע ועוד.
עובדת בדפדפן, ניתנת להתקנה על מסך הבית בטלפון, וממשיכה לעבוד ללא אינטרנט לאחר הטעינה הראשונה.

## מה יש באפליקציה

| מסך | מה מקבלים |
|---|---|
| **בית** | סטטוס המסע, היום הנוכחי בתוכנית, תחזית מזג אוויר (Open-Meteo) עם התרעת עומס חום, מצב העונה לפי אזור, קיצורי דרך |
| **מקטעים** | כל מקטעי השביל מדן ועד אילת: מרחק, שעות, דרגת קושי, אזור, מים/הטמנות, שטחי אש, נקודות עניין, לינה בסיום, תחבורה, קואורדינטות, GPX, סימון "הושלם", הערות אישיות |
| **מפה** | Leaflet עם מפת הטיולים של ישראל / OSM / OpenTopoMap, נקודות מקטעים, חניוני לילה, לינה, מיקום GPS חי, מרחק מהשביל, הורדת התוואי המלא מ-OpenStreetMap לשימוש לא מקוון, ייצוא GPX |
| **תכנון** | מחולל לו"ז: כיוון (צפון→דרום / דרום→צפון), תאריך, קצב יומי, פיצול מקטעים ארוכים, ימי מנוחה, "לא הולכים בשבת", סגנון לינה, טווח מקטעים. מחשב תאריך סיום, תקציב, אזהרות עונה/שטחי אש/הטמנות, ייצוא ליומן (ICS) ושיתוף |
| **ניווט** | מצפן (חיישני המכשיר), אזימוט ומרחק ליעד הבא, קואורדינטות (עשרוניות + מעלות/דקות לחילוץ), גובה ומהירות, זריחה/שקיעה ושעות אור, מד מרחק יומי, שיתוף מיקום ב-WhatsApp, מספרי חירום בלחיצה |
| **מדריך** | עונות ואקלים חודשי, מים והטמנות, מלאכי שביל / חניוני לילה / לינה בתשלום, בטיחות (שיטפונות, שטחי אש, חום, בע"ח, ביטחון), רשימת ציוד אינטראקטיבית, מחשבון תקציב, תחבורה והצטיידות, סימון השביל, שאלות נפוצות, טיול אחראי |
| **יומן** | רשומות יומיות עם מצב רוח, ק"מ, מקטע ומיקום; מד התקדמות; ייצוא |
| **הגדרות** | מצב כהה/בהיר, מפת רקע, גיבוי/שחזור הנתונים (JSON) |

כל הנתונים האישיים נשמרים במכשיר בלבד (localStorage / IndexedDB). אין שרת.

## הרצה מקומית

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # תיקיית dist/ מוכנה לפריסה
npm run preview
```

## פריסה

- **GitHub Pages**: ה-workflow ב-`.github/workflows/deploy-pages.yml` בונה ומפרסם אוטומטית בכל push ל-`main` (יש להגדיר Settings → Pages → Source: GitHub Actions). ה-`base: './'` ב-Vite מאפשר הרצה מכל נתיב.
- **Netlify / Vercel / Cloudflare Pages**: build command `npm run build`, output `dist`.
- חובה HTTPS כדי ש-GPS, מצפן ו-Service Worker יעבדו.

## מקורות נתונים ורישיונות

- **מפות**: [Israel Hiking Map](https://israelhiking.osm.org.il) (אריחים CC BY-NC-SA 3.0, לשימוש פרטי), OpenStreetMap (ODbL), OpenTopoMap.
- **תוואי השביל**: OpenStreetMap relation 282071 דרך Overpass API (מורד לפי בקשת המשתמש ונשמר במכשיר).
- **מזג אוויר**: [Open-Meteo](https://open-meteo.com) (ללא מפתח, שימוש לא-מסחרי).
- **תמונות**: Wikimedia Commons ברישיונות חופשיים; קרדיט מוצג על כל תמונה.
- **מידע על השביל**: החברה להגנת הטבע, רשות הטבע והגנים, ויקיפדיה/ויקימסע, קהילות השביליסטים ומדריכים מקוונים. ראו `docs/research.md`.

> ⚠️ המידע נאסף ממקורות ציבוריים ועשוי להשתנות (שינויי תוואי, סגירות ביטחוניות, שטחי אש, מחירים, מים בחניונים). לפני היציאה יש לאמת מול המפות והאתרים הרשמיים. האחריות על הבטיחות היא של המטייל.
